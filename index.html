Pitching Model Bisnis Startup

  • Value Proposition: Menghemat waktu belajar siswa SMA kelas 11 dengan ringkasan cepat dan latihan hafalan interaktif.
  • Target Pasar: Siswa SMA/SMK seluruh Indonesia yang membutuhkan bahan belajar praktis menjelang ujian.
  • Strategi Monetisasi: Penjualan *Template Ringkasan Premium* (format JSON) dan penempatan sponsor mikro di bagian bawah web.
  • Kelebihan Teknologi: Dibangun murni dengan HTML, CSS, JavaScript (Ringan, tanpa server mahal, bisa di-hosting gratis via GitHub Pages).
